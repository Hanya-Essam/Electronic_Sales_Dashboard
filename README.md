# Electronic Sales Dashboard

The **Electronic Sales Dashboard** is a Power BI project that turns electronics sales data into an interactive report, making it easy to see how products, stores, and customers are performing.

The dashboard is built on a star schema with a central sales table linked to **products, dates, regions, stores, salespeople, customers, and payment methods**.

## Dashboard Pages

- **Home**: an overview with total revenue, total orders, units sold, average order value, and average unit price, plus revenue over time, by product, and by region
- **Sales & Product Insights**: revenue by product and store location, top salespeople, year-to-date revenue, and how discounts relate to revenue
- **Customer & Order Insights**: unique customers, repeat customer rate, returned orders, revenue with promotions, orders by payment method, and average order value by customer type

## Features

- Year and month filters to explore any time period
- Navigation buttons to move between pages
- Custom tooltips that show extra detail when you hover over a chart
- DAX measures for all the KPIs

## Tools Used

- Power BI Desktop
- DAX
- Power Query
